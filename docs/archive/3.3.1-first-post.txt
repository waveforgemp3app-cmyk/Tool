[B][SIZE=4]Phone and tablet beta[/SIZE][/B]

• Hold a bag or equipped item for about 0.6 seconds to pick up its visible icon under your finger. Drag it to a bag cell or compatible equipment slot, then release. Holding alone does not use or equip it. Verified in the original game with trusted touch input: pickup, durable equip/unequip/swaps, invalid-drop retention and retry, cancellation, and no walking through the UI. Shift split and Ctrl preset/tooltip/link controls also passed.

• The signed Android APK, checksum, sanitized provenance and instructions are included in engine/Phone-Tablet. The APK keeps its existing package/signature so it can update earlier previews. Its file/app name still says Private Preview. The owner has tested and approved the updated Android build; that does not establish compatibility with every device.
• The galaxy connection screen and Dekaron icon match the PC Client. The app joins a PC-hosted world: it checks Open/Invite hosts, remembers checked servers and checks changed addresses again before Join. It does not host a world or run the Windows installer.
• Settings/Hosting options can show a server QR. Android scans locally, imports only the address and checks it before you choose Join. Camera permission is optional. Passwords and sign-in tokens are not in the QR; manual entry remains available.
• Same-Wi-Fi joining uses the host's reachable LAN address and port. Away from home needs a reachable HTTPS host/relay or an already-configured VPN; an account password does not make a private LAN address reachable over mobile data. Instructions cover both cases.
• Valid same-host sign-in proceeds to character selection without asking for the same credentials twice. Expired or deliberately changed accounts still require sign-in. Phone connection/account screens stay upright, with larger fields and keyboard-aware internal scrolling. Character selection, creation, loading and play use landscape; tablet connection pages can rotate.
• Fixed the instant-close Android startup error. Gameplay clears leftover portrait insets and uses immersive fullscreen. Android can show its bars briefly after an edge swipe. Renderer-loss recovery is visible, and returning pages wait for pending saves instead of silently reloading past a failed save.
• Original game windows and quickslots remain in use. One gold 48px button sits immediately left of ONLINE; its drawer opens below, stays on screen, clears the minimap and provides larger panel/skill actions. Closing a panel consumes the touch instead of moving the character through the close button.
• Window title bars retain long touch drags while panel-body scrolling stays normal. Touch camera panning is faster; tap/hold ground movement, select-then-attack, two-finger pan/twist/pinch and one-shot Shift/Ctrl modifiers remain available. Native item moves, equip/unequip and swaps retain server ownership and slot checks.
• Connected mouse/keyboard controls remain available. Supported controllers and handheld PCs can use the left stick to move and right stick to pan; controller buttons are not mapped yet.
• iPhone/iPad use the hosted Safari page, optionally Add to Home Screen, with manual rotation. [B]There is no native iPhone IPA in this release.[/B] The Android APK cannot install on iPhone. Phones download and render assets from the host; this is not video streaming or zero-download play.

[SIZE=5][B]2.2.3 - Faster First Start[/B][/SIZE]
[I]The last update of the 2.x line. It has one change: the preparation of the client data that runs on the first start after an install or an update now runs its steps in parallel. The game itself is unchanged.[/I]
[B]Loading[/B]
[LIST]
[*][B]First start after an install or update:[/B] The preparation used to take about 5 minutes (315 seconds on my PC) because its 21 steps ran one after another. Steps that do not depend on each other now run at the same time: the same preparation took 77 and 89 seconds in two runs on a 6-core PC with 32 GB of RAM (3.5 to 4 times faster; a PC with fewer cores gains less). The prepared files are identical to what the old order produced: compared file by file, every byte is the same except the time stamps inside 17 of the 57 data files.
[*][B]How many steps run at once:[/B] up to 4, fewer on a PC with fewer than 5 cores, and at most 2 on a PC with less than 6 GB of RAM (4 at once used up to 3.8 GB of memory on my PC). Set the environment variable DEKARON_PREPARE_JOBS before starting the launcher to choose another number; DEKARON_PREPARE_JOBS=1 runs the steps one after another as before.
[*][B]Safe on errors:[/B] if one step fails or you close the launcher, all running steps are stopped before anything is cleaned up, and the previously prepared data stays in place.
[*][B]One more preparation after updating:[/B] the preparation program itself changed, so every install prepares once after updating to 2.2.3 (about 1.5 minutes now).
[*][B]Changes to the channel files are noticed:[/B] the preparation did not look at the channel rule files (channel-data.mjs, channel-rules.js), so editing them did not rebuild the prepared data. It does now.
[/LIST]

[SIZE=5][B]Features[/B][/SIZE]
A complete alternative engine, client and server for Dekaron. Play solo, host your own shared world for friends, or join someone else's server — plus a full GM panel, an Item Builder and a Map Builder. It uses [B]native Global data[/B] for classes, skills, items, monsters, maps, quests, shops, events and PvP. Where the data does not establish a rule or renderer behaviour, the reconstruction is documented and tagged [B]ENGINE-CHOSEN[/B] (or FITTED when fitted to Global screenshots). The remaining items and limits are listed below. This is not a claim of complete original-executable parity.

[SIZE=5][B]Hosting — play with friends[/B][/SIZE]
[LIST]
[*][B]Your own world:[/B] Start = your local world on this PC. Hosting options = a separate world with its own accounts, name and EXP / DIL / drop rates, Invite only or Open (accounts required). Friends create their own accounts on your server; accounts and characters belong to the server you pick.
[*][B]Connect:[/B] friends enter your server address (or pick it from a saved list), sign up there and launch. Hosting is relay-only by default and the launcher shows no home address; a direct host listens on this PC only until you tick "Allow direct LAN connections" in Settings.
[*][B]Online relay:[/B] the host connects outbound to a managed HTTPS relay you control (named Cloudflare tunnel + token); players get the relay address, never the host's. The relay gateway strips forwarded IPs and caps 24 connections per address.
[*][B]Guided setup:[/B] four buttons — On this PC / My own VPS / Vercel / Cloudflare — write step-by-step guides and files under hosting-setup\; they deploy nothing and create no accounts. Docker / Railway / Render templates and a static Vercel / Cloudflare Pages connector are included for a persistent server.
[*][B]Public server list:[/B] optional; it asks with a warning, records your consent, can be switched off in Settings without stopping the relay, and only lists on a directory address you set. The project runs no public directory.
[*]Closing the game returns to the dashboard while your server stays running; closing the owned-server dashboard or clicking Stop Server saves and stops it.
[/LIST]
